## Requirements
* Code Composer Studio - https://www.ti.com/tool/CCSTUDIO#downloads 

## Update CCS with CC35x1 support
* Unzip archive file cc3500_ccs_legacy_[OS]_support_6544.[VERSION].zip in to folder
* Copy content of unzipped file into <CCS_INSTALL_DIR>/ccs/ccs_base
* Open terminal / cmd and navidate into <CCS_INSTALL_DIR>/ccs/ccs_base/scripting/examples/CC35xx
